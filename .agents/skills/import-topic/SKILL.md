# Instructions
 
1. Identify the content to import. Can be provided as a URL or already pasted into the current document.
1. Identify the topic type - such as 'task', 'concept' or 'reference' - according to the content.
1. Identify the topic template as described in the skill 'create topic'.
1. Copy the corresponding template's content to the top of the new or existing topic file.
1. Convert the external content from its source format (such as markdown or html) to the target format (AsciiDoc or DocBook)
